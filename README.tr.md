## 🚀 Yourdest

İstanbul ve Tekirdağ'da mekan keşfi ve öneri uygulaması. Ürünün tamamını tek başıma tasarlayıp geliştirdim ve 12 ayda fikirden App Store'a taşıdım.

- **5 kod tabanı:** Flutter mobil uygulama · .NET backend · 2 React yönetim paneli · kurumsal web sitesi
- **15'ten fazla entegre servis:** Railway, Cloudflare, Netlify, Resend, Firebase, iyzico, Google Maps, Gemini API
- **Mağaza yayınları:** App Store ve Google Play inceleme süreçlerini baştan sona yürüttüm (3 ret → düzeltme → onay)
- **Ürün tarafı:** paketler ve fiyatlandırma, deneme modeli, öneri felsefesi, kullanıcı deneyimi
- **İş tarafı:** şirket kuruluşu, ödeme altyapısı onayı, KVKK / e-ticaret uyumu

🌐 [yourdest.com](https://yourdest.com) · 🍎 [App Store](https://apps.apple.com/tr/app/yourdest/id6766088371) · 🤖 [Google Play](https://play.google.com/store/apps/details?id=com.yourdest.app)

> Kod gizlidir. Örnekler talep üzerine paylaşılabilir.
